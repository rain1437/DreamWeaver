# 常见问题

## 数据与隐私

**数据存在哪里？会上传吗？**
全部存在你自己浏览器的 `localStorage` + `IndexedDB` 里。本项目没有后端，没有账号体系，
没有埋点统计。你的小说内容与 API Key 都不会离开这台设备。

**换设备 / 换浏览器，数据还在吗？**
不在。本地存储是按「浏览器 + 域名」隔离的。换之前请到 **🛡 数据保险 → 导出全部备份**，
在新设备上 **导入** 即可。

**清缓存会丢数据吗？**
可能。所以应用内置了四层防护：IndexedDB 镜像、自动快照、整库备份、存储体检。
但仍建议养成**定期导出备份**的习惯。无痕模式下浏览器明确不允许持久保存，应用会在顶部给出红色警告。

**为什么在无痕窗口里打开就提示风险？**
无痕模式关闭窗口即清空所有存储，且不允许申请持久化权限。此时建议只做临时体验，不要正式写作。

## 使用相关

**不填 API Key 能用吗？**
能。会进入**演示模式**，用内置文本走通全流程，适合先熟悉界面。

**支持哪些模型服务？**
任何 OpenAI 兼容接口，包括 OpenAI、DeepSeek、通义千问、硅基流动、Moonshot、智谱等，
以及本地 Ollama / LM Studio（填 `http://localhost:11434/v1` 之类）。

**接本地 Ollama 报跨域 / 混合内容错误？**
两个办法：
1. 用「单文件版」直接双击打开（`file://` 协议），本地请求不受混合内容限制；
2. 或给浏览器启动参数加白名单，或用应用内「下载本地代理脚本」跑一个小中转。

**「叙事地位九级」是什么？和角色强弱有关吗？**
无关。它只看**叙事权重**（戏份、弧光、对主线的影响），用来控制 AI 给多少笔墨。
世间无敌的大帝可以只是「功能性NPC」，底层乞丐也可以是「第一主角」。
分类：第一主角 / 对等双主角 / 第二主角 / 核心配角 / 重要配角 / 普通配角 / 功能性NPC / 背景路人 / 传说人物。
你也可以**自定义档位**（新增、改名、插到任意位置）。

**AI 梳理角色时会乱改我的设定吗？**
不会。主角类与重要配角（以及所有你手工定过的卡）默认**受保护**，AI 只能在报告里给建议，
需要你点「采纳」才会生效。关系核查同样是「只提示、不自动改」。

**出文时正文里会混进「下一章建议」吗？**
不会。提示词里明确禁止，且每次写入正文前都会做一次净化（只在正文尾部命中「章节小结/下一章建议」
这类元信息小标题时才截断，剧情里的正常对话不受影响）。建议卡片始终独立显示，不写入正文。

**AI 会自己编造人物和设定吗？**
默认开启「🌟 严格遵守已有信息」铁律：不允许凭空产生人物姓名、地名、门派、数值等；
资料没写到的地方会留白（例如写成「一名侍卫」）。可在出文 ⚙ 高级选项里关闭。

## 手机 / 安装

**怎么装成 App？**
见 [`部署到-GitHub-Pages.md`](部署到-GitHub-Pages.md) 第三节。简单说：用 https 打开 → 浏览器菜单
→「安装应用 / 添加到主屏幕」。iOS 必须用 Safari。

**从桌面版切到手机版需要设置吗？**
自动识别。也可以在 **数据保险 → 界面适配** 里手动强制「手机版 / 电脑版」。

**手机上界面元素太小 / 太空？**
设置里有「🎨 外观」：可切换 **宽松 / 紧凑便携** 两种布局密度，也能关掉装饰动画省电。

**离线能用吗？**
界面可以（已装成 App 后缓存了外壳），但 AI 生成需要网络，除非你接的是本地模型。

## 开发者

**改了源码，怎么出成品？**

```bash
npm run build     # 产出 index.html
npm test          # 全套自检
```

**改了应用内容，线上没更新？**
把 `sw.js` 里的 `VERSION` 加一，让 Service Worker 换缓存。

**测试里那些 `body-*.js` 是干什么的？**
测试体。`harness.js`（脚手架）+ `body-*.js`（测试体）= `test-*.js`。
改完 body 后跑 `npm run tests:gen` 重新生成。

**为什么应用是「一个文件」，源码却这么多？**
成品追求「双击即用、可随身带」，源码追求「可维护、可测试」。
`build.js` 负责把模块拼接、注入并逐项自检，任何一项不通过就拒绝产出——
这能有效防止手改产物导致的隐性破坏（这个项目历史上真被 `String.replace` 吃掉过 `$$`）。

防跑偏工作流

每次生成正文，系统按顺序拼装上下文：
⓪ 全局总提示词 + 世界观设定库（固定上下文，写入 System Prompt）→ ① 创世设定 → ② 本章出场角色卡 → ③ 命中的世界书条目（含常驻条目）→ ④ 已编入目录的前情与章节梗概 → ⑤ 上一章结尾 → ⑥ 本章梗概要求。

世界书采用关键词触发（和 SillyTavern 同一套逻辑）：上文扫描范围内出现关键词，对应设定才会注入， 因此几十万字的设定集也不会撑爆上下文；标记为常驻的条目则每章都注入。

三步开始织梦

支持 SillyTavern 的世界书 JSON、角色卡 JSON / PNG（角色卡内嵌的世界书条目会一并导入并绑定到该角色）。
这里录入的内容会作为固定上下文，每次生成章节时拼进 System Prompt，保证设定统一不崩。
四大模块相互独立、按需填写（写现代小说可以直接关掉「力量体系」）。每条设定单独保存、单独让 AI 扩写或润色，互不影响。
世界书已完全并入这里：在「🌍 世界百科」里可以导入 SillyTavern 世界书，触发关键词、常驻、概率、分组、递归等设置全部保留； 力量体系 / 历史年表 / 全局约束属于固定上下文（每章必注入）。
支持 SillyTavern V1 / V2 / V3 角色卡（含 PNG 内嵌卡）。点开卡片进入人物档案， 按「角色档案 / 形貌特征 / 性格内核 / 口吻腔调 / 身世履历 / 能力谱系 / 关系星图 / 目标驱动 / 角色铁律」分格填写， 只有填写过的格子才会注入提示词。可设置出场章节范围，避免几十个角色互相干扰。
本工具写的是小说、不是对话：卡里的 {{user}} / {{char}} 占位符会在导入时自动清理， 开场问候语一类对话专用内容会被丢弃。
叙事地位（9 级 + 自定义档位）：第一主角 / 对等双主角 / 第二主角 / 核心配角 / 重要配角 / 普通配角 / 功能性NPC / 背景路人 / 传说人物， 还可在「⚙ 自定义分类」里加自己体系里的档位（例：幕后黑手 / 情感线女主），它们会和内置档位一起排序、一起参与写作权重。 点卡片或档案页上的定位徽标就能改。只看剧情作用与戏份，与实力、官职、世界观社会地位无关—— 世间无敌的大帝可以是功能性NPC，底层乞丐可以是第一主角。每章注入时按权重从高到低排序， 并把「权重排序 + 写作约束」一并写进提示词，低地位角色不会抢夺主线戏份。
AI 不得擅改地位：主角类、双主角、核心/重要配角以及你自己手工定过的卡，梳理时只会给出建议，必须你确认才会生效。 主角一般由你导入；其余档位可以让「✦ 从正文梳理角色」自动总结，导入 SillyTavern 卡时也会自动判定一档。 人物关系会自动整理成关系表与关系图（点越大＝地位越高），并在生成时一并注入，保证人物关系不崩。
留空则统一用「主角」。
